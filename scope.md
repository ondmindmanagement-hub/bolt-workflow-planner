# Scope

## User
A founder or builder planning a small AI-assisted workflow.

## Problem
Builders often start automating before deciding which actions should remain under human control.

## Goal
Turn one plain-language task into a short workflow and explicitly mark a consequential action as requiring human approval.

## Must have
- Task input
- Risky-action input
- Five-step generated workflow
- Explicit human-approval boundary
- Runs locally in a modern browser

## Out of scope
- External model APIs
- Accounts
- Cloud deployment
- Full BOLT policy engine
- Automatic execution of real-world actions

## Definition of done
A user can enter a task and risky action, generate a workflow, and understand where approval is required in under one minute.
