# Build plan

## User
A founder or builder planning a small AI workflow.

## Job to be done
Before writing automation code, identify the main steps and the point where human approval is required.

## Must have
- Task input
- Risky-action input
- Generated workflow
- Explicit approval boundary
- Runs locally with no setup

## Not in scope
- External model API
- Accounts
- Cloud deployment
- Full BOLT policy engine

## Definition of done
A stranger can open the page, enter a task and risky action, and understand the planned workflow in under one minute.
