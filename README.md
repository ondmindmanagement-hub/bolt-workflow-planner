# BOLT Workflow Planner

A small proof-of-concept built for **Build With AI: Basics**.

## Problem

People often start AI automation by coding first and deciding control boundaries later.

## Scope

One core job: turn a plain-language task into a tiny workflow plan that explicitly marks where human approval is required.

## What the POC does

1. Takes a task.
2. Asks for the risky or consequential action.
3. Produces a five-step workflow.
4. Marks the consequential action as requiring human approval.
5. Keeps the output simple enough to review before implementation.

## Why this scope

The goal was to finish one useful end-to-end idea in an afternoon-sized project rather than reproduce the full BOLT platform.

## Run

Open index.html in any modern browser.
